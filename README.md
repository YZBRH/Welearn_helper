# 功能

- 刷学习时长与正确率：合并为一个入口，每个练习先学习指定时长（如 30 或 10,30），完成后再按需提交正确率
- 正确率可选：填写固定正确率（如 100）或随机区间（如 70,100）；留空则只刷时长并保留已有正确率、完成状态
- 兼容原正确率模式：只填写正确率、时长留空时，继续使用原来的 20–40 秒默认学习时长与 4–10 秒间隔
- 可配置并行计时：支持同时为 1–4 个小节计时，网络提交仍串行保护；默认 1，并发越高越容易触发平台风控
- 正确率稳健写入：先在完整学习时长后提交正确率、完成状态和学习时长，避免零时长记录被服务端后续清空
- 统一学习内核：心跳计时、CMI 读取、停止处理和提交协议只维护一份
- Web 图形界面：任务在后台线程运行不卡顿、可随时停止、日志实时滚动
- 支持多选单元、单元内多选小节（不勾选小节 = 刷整个单元）
- 保留命令行入口

# 使用

## 环境准备

本机运行使用 `D:\Python\python.exe`（Python 3.13.2），然后安装依赖：

```
D:\Python\python.exe -m pip install -r requirement.txt
```

## 图形界面(推荐)

双击 一键启动.bat，或手动运行：

```
D:\Python\python.exe -u web_gui.py
```

启动后自动打开浏览器 http://127.0.0.1:17777/ ，按 Ctrl+C 退出。

操作流程：输入账号密码并登录 → 选择课程 → 勾选单元（或勾选“全部单元”）→ 可展开单元勾选小节 → 填写学习时长、可选正确率和并发计时数 → 开始任务。任务运行中可随时点击“停止”。

学习时长默认填 `20,40`，即每个练习随机学习 20–40 秒；正确率留空时不会修改已有正确率。只刷正确率时保留时长默认值即可。

可选环境变量：

- `WELEARN_PORT`：修改监听端口（默认 17777）
- `WELEARN_NO_OPEN=1`：跳过自动打开浏览器（适合无桌面/远程环境）

## 打包 / 使用 Windows 可执行文件

从 GitHub Release 下载 `WelearnHelper.exe` 后直接双击运行，无需安装 Python；程序会在本机启动 Web 图形界面并自动打开浏览器。

本仓库维护者可重新打包：

```
python -m pip install -r requirement.txt -r requirements-dev.txt
powershell -ExecutionPolicy Bypass -File scripts/build_exe.ps1
```

打包产物为 `dist/WelearnHelper.exe`。推送 `v*` 标签后，GitHub Actions 会运行测试、打包并把 EXE 与 SHA-256 校验文件上传到 GitHub Release。

## 命令行
双击 命令行启动.bat，或手动运行：

```
D:\Python\python.exe -u main.py
```

按菜单提示操作：1 刷学习时长并按需写入正确率，0 退出。时长和正确率均支持单个数值或英文逗号分隔的区间；时长单位为秒，正确率为百分数。时长直接回车时使用默认的 20,40，正确率直接回车时保留原值。

## Docker

仓库自带 Dockerfile（命令行模式，无需本机安装 Python）：

```
docker build -t welearn-helper .
docker run -it --rm welearn-helper
```
